# eBay Playwright Automation

This automation project contains test cases that verify the Similar Products section on an eBay product page.

---

## Prerequisites

Before running the project, following should be installed/fullfilled:

1. Install Java  
2. Install Maven  
3. Install Git  
4. Create GitHub account  
5. Install IntelliJ or any IDE of your choice  
   

---

##  Getting Started

### 1. Clone the Repository

Create a folder on your local machine called "EBay-Playwright-Automation":


Open **Git Bash** inside the same folder and run

```bash
git clone https://github.com/onashase/eBay-Playwright_automation.git
```

### 2.Checkout to branch "feature/similar_products_tests"

```bash
git checkout feature/similar_products_tests
```

### 3. Open this project in Intellij or any IDE

### 4. Update Maven Dependencies by running this command in your IDE terminal

```bash
mvn clean install
```

### 5. Navigate to -> src/test/java/tests/eBayRelatedProductsTest.java and Execute Tests
